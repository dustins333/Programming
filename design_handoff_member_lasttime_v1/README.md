# Last time | getting the reference out of the input box

Surface: My Fitness, live session logging. Turn 15 in *Kova Member Mobile - Directions.dc.html* (`#15a`, `#15b`).

**Decision: B — blank card, tap for everything (`#15b`).** The card carries no last-time reference at all; the lift name opens a history sheet that answers "what have I done" in one glance.

---

## The card

**Nothing under the lift name.** No last-time line, no per-set chip, no summary of what was asked for. The header is the lift name and the two controls, and that is all.

**Empty sets carry the programmed target, not a past number.** An unkeyed box is dashed, tinted `#fdfbf8`, and holds the prescription — `8–10` in near-white clay `#d5cdc4` beside a tiny `GOAL` tag. What sits in an empty field is what the coach asked for, and it is unmistakably not hers:

| | unkeyed | keyed |
|---|---|---|
| border | 1.5px dashed `#ddd6cd` | 1px solid `#dbe8cf` |
| ground | `#fdfbf8` | olive tint `#f3f6ef` |
| value | `#d5cdc4`, 17px, + `GOAL` | `#44403c`, 20px |

The set she is on keeps the clay border and caret. Weight has no programmed value, so its empty box holds a light en dash.

**Two targets in one header.**

- **Lift name = history.** Set number stays `#44403c`; the name is clay `#a46a57`. On the **open** lift only, a 17px peach chevron mark follows the name — the affordance appears where she can act on it and never clutters the collapsed list.
- **Chevron = collapse.** Its own glyph in a 44pt bordered circle at the right edge, peach on the open card, so it reads as a control rather than as text.
- The completion checkbox sits between them, unchanged.

## The history sheet

Bottom sheet, 22px top radius, over a `#44403c` 35% scrim. Grab handle plus a 44pt **Done**. It covers the input fields while open — accepted: she reads, dismisses, loads the bar, then types. No chart.

1. **Three sessions, one row each** — date, "10 days ago", and every set as its own pill (reps large, weight small beneath). Pills align in columns down the three rows, so comparing set-by-set takes no reading.
2. **Most recent row is tinted peach and tagged `LAST TIME`** — the reference is found without searching.
3. **`View full history ›`** — full-width clay button, opens My History with this exercise pulled out. Everything deeper than three sessions (trend, bests, full log) lives there, in the visual language it already has.

## Why B over A

A's `last: 3 × 10 @ 135 | Aug 5` line is genuinely cheaper in the moment, but the card it produces is busier on every lift, all session, to serve a question she only asks on some of them — and the GOAL-in-box treatment already tells her what today is supposed to be, which is most of the decision. B keeps the logging card down to the two things she is doing (keying numbers, ticking lifts) and puts the reference exactly one tap away. `#15a` stays in the file as the fallback if testing shows the tap is being skipped rather than taken.

## Open questions

1. **What the sheet's "last time" resolves to** — the last time she logged this lift, or the same slot in the previous week of the block? They diverge as soon as she skips a session.
2. **Fewer than three sessions.** One or two rows, or one row plus an empty state? A first-time lift has nothing at all — does the mark still show on the name?
3. **Uneven set counts.** Aug 5 has three sets, today asks four. Should the sheet's rows pad to today's set count so the columns line up, or stay exactly as logged (current)?
4. **`GOAL` as a word.** It is the clearest label but it is not language used anywhere else in the app — alternatives: `TARGET`, `ASKED`, or the tag dropped entirely and the value left pale.
5. **Rest time** is still absent from these cards; the pinned timer from turn 9 is assumed unchanged.
