Unified "Today" + a real Nutrition dashboard
Member: Today is a status overview, not a logging surface — session shows as a read-only preview (exercise + set/rep targets, no input fields) with a "Start session" CTA that hands off to the actual logging screen; nutrition shows either what's already logged (weight trend, % of calorie target) or a "you haven't logged yet" nudge, never an inline form. Workout (3x/week) and nutrition (daily) sit together since a member checks both once a day. Deeper work — actually logging sets, the full nutrition form, check-in, history — lives in Plan/Nutrition.
Coach: nutrition is a full primary tab with its own roster dashboard (status chips, filters) — matching SPC's depth — instead of a single link tile. Coach Home is an attention-first overview, not a flat list of destinations.
